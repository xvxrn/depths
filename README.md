# depths

A tiny roguelike for the terminal. Procedural dungeons, permadeath, no dependencies beyond curses (stdlib).

## Play
```
depths
```

## Controls
- Move: arrows / WASD / hjkl; diagonals: yubn
- `p` drink potion, `r` read scroll, `>` descend stairs, `q` quit

## Goal
Reach floor 10 and escape. Each floor gets harder; bosses every 5 floors.

## Items
- `!` potion (heal), `/` weapon (ATK), `[` armor (DEF/HP), `$` gold, `?` scroll (reveal/fireball/teleport)
